# Store Listing & Console Text

## Short description (EN)

Wake up with the sunrise. Daily sunrise-based alarms with location, precise timing, and gentle UI.

## Full description (EN)

Sunrise Alarm helps you wake up naturally with the sun.

- Auto-calculated sunrise time for your location
- Precise alarms that work even when the app is closed
- Daily repetition with automatic future scheduling
- Custom sounds, vibration, and 24h/12h formats

Permissions:

- Location: to compute local sunrise time
- Notifications & Exact Alarms: to deliver alarms reliably at the right time

We do not collect personal identifiers. Location is used ephemerally to query sunrise time via https://sunrise-sunset.org.

Privacy: https://gusto-dev.github.io/sunrise_alarm/privacy.html

## Data Safety (console hints)

- Data collected: Location (precise)
- Data shared: Location (to sunrise-sunset.org for core functionality)
- Purpose: App functionality (alarm scheduling based on sunrise)
- Data linked to user: No
- Data is sold: No
- Security: Data is encrypted in transit (HTTPS)

## Sensitive permission: Exact alarm (console justification)

This app is an alarm/reminder app. Exact alarm is required to ring precisely at the scheduled time (sunrise-based). Users are informed in-app, and the permission is used solely for alarms.
